## Summary

A user without access to Android USB could open the alpha but could not exercise its automation workflow. Add explicit offline demo sessions inside the existing Qt/Monaco application: real generated pixels and state transitions, OpenCV matching, screenshot tools, recorder and spawned workers. Simulation uses separate capability-bound identities/transport; it never enters ADB discovery or silently replaces a failed phone.

- Three scenarios: image click, delayed reward/waits and recorded/swiped workflow; independent sessions, reset/stop and saved sample projects.
- Optional real local Tesseract OCR with five documented short/device APIs, immutable text boxes, cancellation/deadlines and no automatic downloads.
- Image preprocessing and a frozen image/OCR/color inspector with overlays, original coordinates, pixel sampling and ordinary Python insertion/completion.
- Pre-tap recorder evidence, bounded JSON v2 with v1 loading, duration/type/device metadata, crop/save conversion to real image targets/offsets and existing trusted replay.
- Small Phase 7 foundation: typed failure guidance and matching-source navigation; no automatic retry, breakpoint/debug service or placeholder debugger controls.

## Windows and hardware

Windows 10/11 x64 remains the target. Spawn-compatible workers, native paths/owned process cleanup and source CI matrix are retained; this increment has **no Windows runtime/CI result**. No physical Android phone was accessible; simulation tests do **not** validate USB, authorization, scrcpy on a phone, native rotation/touch or real APK behavior. The user's PC-level USB issue is not claimed fixed.

## Limitations / remaining work

Fixed 360×720 simulator; no Android services/APKs/IME/sensors/rotation/physical gesture timing. Optional OCR requires an existing trusted executable/local language data and can misrecognize text. Preprocessing is explicit, not an accuracy guarantee. Recorder conversion requires a real saved textured pre-tap crop; full external-touch/multitouch recorder and drag/drop timeline are deferred. Full DAP breakpoints/stepping/locals/debug console, automatic recovery/persistent history, scheduling, sustained performance and Windows/real-device acceptance remain follow-ups. No installer is included.
